# Export demo clip

The supplied clip is **`export-window.mp4`**: 1920×1080, 60 fps, 12 s, H.264,
no audio. The export page plays it muted and inline inside the particle monitor;
when it ends, the monitor compresses into a line and the line unfolds into the
export methods. `export-window-poster.jpg` is the first frame (0.1 s) and stands
in while the clip loads; the dashed video slot is only a fallback for a missing
file or playback failure. The last frame stays on the screen through the
collapse.

To replace it, keep the same name and path; a 16:9 H.264 MP4 without audio is
the safest choice.
